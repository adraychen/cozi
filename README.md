# 📊 Data Analytics App

A multi-section data analytics tool built with Streamlit. Upload a CSV or Excel file and the app will inspect your data, run a quality audit, visualise every column, explore relationships between columns, and run machine learning models — all explained in plain English.

---

## Sections

| Section | What it does |
|---|---|
| **Dataset Overview** | Row/column counts, scrollable data preview, boolean columns shown as True/False |
| **Column Overview** | Per-column table: data type, column type, total values, missing values, missing % (colour-coded) |
| **Data Quality Summary** | Tabbed quality panels with charts and stats for Numerical, Categorical, and Date/Time columns |
| **AI Interpretation** | Plain-English summary of dataset quality generated by Groq (Llama 3.3 70B) |
| **Data Exploratory Analysis** | Single-column deep-dive (Column Profile) and multi-column chart explorer (Column Relationships) |
| **Predictive Analytics** | Automated model comparison and selection for regression and classification problems |

---

## Dataset Overview

- Accepts CSV (`.csv`) and Excel (`.xlsx`, `.xls`) files
- Displays **Rows** and **Columns** as metric tiles immediately after upload
- Shows the first 100 rows in a scrollable table
- Boolean columns rendered as `True` / `False` text (not checkboxes)

---

## Column Overview

One row per column showing:

| Column | Description |
|---|---|
| Column Name | Original column name |
| Data Type | Plain-language dtype: Whole Number, Decimal Number, Text, True/False, Date/Time |
| Column Type | Classified as Numerical, Categorical, or Date/Time |
| Total Values | Total row count |
| Missing Values | Count of missing entries |
| Missing % | Percentage missing, formatted to 2 decimal places |

**Colour coding:** Red = 20%+ missing. Yellow = 5–19% missing.

**Date/Time override:** A multiselect below the table lets users reclassify any column as Date/Time. Columns where fewer than 80% of values parse as valid dates are rejected with a warning message.

---

## Column Type Detection

| Type | Detection logic |
|---|---|
| **Numerical** | Pandas `int` or `float` dtype, excluding `bool` |
| **Categorical** | `object` dtype, `bool` dtype, or columns that cannot be reliably parsed as dates |
| **Date / Time** | `datetime64` dtype, or `object` columns where 80% or more of non-missing values parse as dates |

> **Boolean columns** are classified as Categorical — True/False values represent discrete categories, not quantities.

## Data Quality Summary

Three tabbed panels, each rendered as bordered cards (two per row):

### Numerical Columns

**Continuous** (15 or more unique values):
- Left: histogram stacked above a boxplot
- Right: Missing Values, Missing %, Unique Values, Minimum, Maximum, Average (all to 2 dp)

**Discrete** (fewer than 15 unique values):
- Left: vertical bar chart sorted descending, capped at 10 bars
- Right: same stats as continuous

> The threshold of 15 unique values is defined as `DISCRETE_THRESHOLD = 15` in `utils/charts.py` and applied consistently across the app, including target type detection in Predictive Analytics.

### Categorical Columns
- Left: vertical bar chart, top 10 by frequency, sorted descending
- Right: Missing Values, Missing %, Unique Values, Case Inconsistency, Special Characters

### Date/Time Columns
- Left: histogram stacked above a boxplot
- Right: Missing Values, Missing %, Earliest Date, Latest Date, Date Range

## Data Exploratory Analysis

### Column Profile (single column)

Select any column from a dropdown for a detailed deep-dive.

**Numerical columns:**
- Distribution chart (bar chart for discrete, histogram + boxplot for continuous) alongside a violin plot
- Summary statistics: Count, Mean, Median, Std Dev, Skewness, Kurtosis, Min, Quartile 1/2/3, Max
- IQR-based outlier detection: count, percentage, lower/upper bounds
- AI interpretation (cached per column, expandable)

**Categorical columns:**
- Frequency bar chart with configurable bar count slider (5 to 50 bars)
- Frequency table with percentage; values below 1% highlighted in yellow
- AI interpretation (cached per column, expandable)

**Date/Time columns:**
- Time series record count chart with Day / Week / Month / Year aggregation toggle
- Summary statistics: Count, Missing Values, Earliest Date, Latest Date, Date Range, Most Common Year/Month
- AI interpretation (cached per column, expandable)

---

### Column Relationships (multi-column)

Select columns using checkboxes grouped by type. Available chart types appear automatically based on the combination selected:

| Column selection | Available charts |
|---|---|
| 2 categorical + 1 numerical | Heatmap — Numerical Values |
| 1 numerical + 1 categorical | Boxplot — Distribution by Category |
| 1 datetime + 1 or more numerical | Line Chart — Trend |
| Exactly 2 numerical | Scatter Plot — Correlation, Interaction Chart — Density |
| 2 or more numerical | Heatmap — Multiple Correlations (with AI interpretation) |
| Exactly 2 categorical | Heatmap — Occurrence, Interaction Chart — Grouped Bar |

## Predictive Analytics

### Flow

1. **Select Target Column** — the column to predict
2. **Predictor Columns** — checkboxes grouped by column type; columns suspected of being identifiers are flagged with a warning
3. **Model** — the app detects the problem type, explains the model choice, and shows a hyperparameter configuration table with an estimated training time
4. **Run** — trains models and displays results; configuration collapses when results appear

### Target Type Detection

| Condition | Type | Models run |
|---|---|---|
| Exactly 2 unique values (any dtype including 0/1) | Binary | Logistic Regression vs RF Classifier |
| Numerical, fewer than 15 unique values | Discrete (multi-class) | RF Multi-class Classifier |
| Numerical, 15 or more unique values | Continuous (regression) | Lasso vs RF Regressor |
| Categorical, 3 or more unique values | Multi-class | RF Multi-class Classifier |

> Numerical columns with exactly 2 unique values (e.g. 0/1) are treated as binary classification, not regression. The binary check runs before the numerical type check.

### Regression Comparison (Lasso vs Random Forest)

Both models trained simultaneously. Winner determined by Test R². All steps run in a single sklearn Pipeline.

**Lasso Regression** — StandardScaler applied automatically to numerical features. Alpha (regularisation strength) tuned via GridSearchCV.

**Random Forest Regressor** — no scaling required. Depth, split, and leaf parameters tuned.

**Hyperparameter grid:**

| Model | Parameter | Values tested | Fits |
|---|---|---|---|
| Lasso | Alpha | 0.001, 0.01, 0.1, 1, 10 | 25 |
| Random Forest | Max depth | 10, 15 | — |
| Random Forest | Min samples to split | 5, 10 | — |
| Random Forest | Min samples per leaf | 3, 5 | 40 |
| Combined | CV folds | 5 | **65 total** |

**Results:** comparison table (green = better value per metric), winner announcement, metric cards (R², RMSE, MAE, CV Mean R²), learning curve (R²), feature importance (RF) or coefficient chart (Lasso), SHAP summary plot.

### Binary Classification Comparison (Logistic Regression vs Random Forest)

Both models trained simultaneously. Winner determined by Test F1 Score.

**Logistic Regression** — StandardScaler applied automatically. Penalty type and regularisation strength tuned. Coefficients converted to odds ratios when LR wins. Class weights balanced.

**Random Forest Classifier** — no scaling required. Class weights balanced.

**Hyperparameter grid:**

| Model | Parameter | Values tested | Fits |
|---|---|---|---|
| Logistic Regression | Penalty | l1, l2 | — |
| Logistic Regression | C | 0.01, 0.1, 1, 10 | 40 |
| Random Forest | Max depth | 10, 15 | — |
| Random Forest | Min samples to split | 5, 10 | — |
| Random Forest | Min samples per leaf | 3, 5 | — |
| Random Forest | Max features | sqrt, log2 | 80 |
| Combined | CV folds | 5 | **120 total** |

**Results:** comparison table, winner announcement, metric cards (F1, Accuracy, Precision, Recall, ROC-AUC), confusion matrix + ROC curve, learning curve (F1), feature importance (RF) or coefficient chart + odds ratio table (LR), SHAP summary.

### Multi-Class Classification (Random Forest)

Single RF Multi-class Classifier with `f1_weighted` scoring and `class_weight='balanced'`. Used for: categorical targets with 3+ classes, and numerical targets with 3–14 unique values.

**Results:** metric cards (Accuracy, F1 weighted, Precision weighted, Recall weighted, ROC-AUC OvR), confusion matrix, learning curve (accuracy), feature importance, SHAP summary with class selector dropdown.

### ID Column Detection

Predictor columns are scanned for likely identifiers before training:
- Column name contains a whole-word match for: `id`, `key`, `index`, `code`, `uuid`, `ref`, `pk`
- Integer columns where 95%+ of values are unique

Float columns are excluded from uniqueness checks — continuous floats are almost always measurement data, not identifiers.

## Charts Reference (`utils/charts.py`)

All charts use a consistent visual style: blue primary colour (`#4C72B0`), white background, dark axis labels, light grey gridlines. Compatible with both light and dark Streamlit themes.

### Quality and Profile Charts

| Function | Signature | What it produces |
|---|---|---|
| `make_histogram_boxplot` | `(series, height=300)` | Histogram (top) stacked above boxplot (bottom) on a shared x-axis. Used for continuous numerical and date/time columns. |
| `make_bar_chart` | `(series, max_bars=10, height=300)` | Vertical bar chart of value counts, sorted descending, capped at `max_bars`. Returns `(figure, was_truncated, total_unique)`. |
| `make_violin` | `(series, height=300)` | Violin plot with embedded boxplot and mean line. Used in Column Profile alongside the distribution chart. |
| `make_time_series` | `(series, freq="M", height=360)` | Line chart of record counts aggregated by time period. `freq`: `"D"` day, `"W"` week, `"M"` month, `"Y"` year. |

### Column Relationships Charts

| Function | Signature | What it produces |
|---|---|---|
| `make_line_chart` | `(df, x_col, y_cols, height=400)` | Multi-series line chart. One line per column in `y_cols`, coloured from the `LINE_COLORS` palette (8 colours). |
| `make_heatmap` | `(corr_df, height=460)` | Correlation matrix heatmap. Red–Blue diverging scale (RdBu_r), values annotated in cells, scale fixed at –1 to +1. |
| `make_scatter` | `(x, y, x_name, y_name, height=400)` | Scatter/dot plot with 55% opacity markers. Correlation coefficient shown as caption below the chart. |
| `make_density_contour` | `(x, y, x_name, y_name, height=420)` | 2D density contour (Blues scale) with faint individual data points underneath for context. Complements scatter by showing where data clusters. |
| `make_occurrence_heatmap` | `(df, col_a, col_b, max_cats=10, height=460)` | Pivot-table heatmap showing how often each combination of two categorical columns occurs. Blues scale, count annotated in cells, capped at `max_cats` per axis. |
| `make_grouped_bar` | `(df, col_a, col_b, max_cats=10, height=420)` | Side-by-side bars. For each value of `col_a` on the x-axis, one bar per value of `col_b`, coloured from the multi-series palette. |
| `make_boxplot_by_category` | `(df, num_col, cat_col, max_cats=15, height=420)` | One boxplot per category, sorted by median descending, mean line shown. Returns `(figure, was_truncated, total_cats)`. |
| `make_pivot_heatmap` | `(df, cat_a, cat_b, num_col, max_cats=10, height=460)` | Heatmap of the mean of a numerical column for each combination of two categorical columns. Red–Yellow–Blue diverging scale, mean value annotated in cells. |

### Predictive Analytics Charts

| Function | Signature | What it produces |
|---|---|---|
| `make_feature_importance_chart` | `(feat_imp, height=450)` | Horizontal bar chart of top 20 feature importances sorted descending. `num__` / `cat__` prefixes stripped from feature names automatically. |
| `make_learning_curve_chart` | `(train_sizes, train_scores, val_scores, height=380, score_label="Score")` | Training vs validation score as training size grows. ±1 std dev shown as shaded bands. `score_label` sets the y-axis title — pass `"R² Score"`, `"F1 Score"`, or `"Accuracy"` as appropriate. |
| `make_coefficient_chart` | `(coef_series, height=450)` | Horizontal bar chart of top 20 coefficients by absolute value. Blue = positive coefficient (increases target), orange = negative (decreases target). Dotted zero reference line. |
| `make_confusion_matrix` | `(cm, labels, height=360)` | Heatmap confusion matrix with count annotated in each cell. Blues colour scale, no colour bar. Row labels = Actual, column labels = Predicted. |
| `make_roc_curve` | `(fpr, tpr, auc_score, height=360)` | ROC curve with AUC score in the legend. Grey dashed diagonal reference line (random classifier baseline). |

### Constants

| Constant | Value | Purpose |
|---|---|---|
| `DISCRETE_THRESHOLD` | `15` | Columns with fewer unique values are treated as discrete (bar chart). 15 or more are treated as continuous (histogram + boxplot). Also used by target type detection in Predictive Analytics. |
| `CHART_COLOR` | `#4C72B0` | Primary blue used for all single-series charts |
| `LINE_COLORS` | 8-colour palette | Cycle of colours for multi-series charts (line chart, grouped bar) |

## Installation

### Requirements

- Python 3.9 or later
- A [Groq API key](https://console.groq.com) (free tier available)

### Setup

```bash
# 1. Clone or download the project
git clone https://github.com/your-username/data-analytics-app.git
cd data-analytics-app

# 2. Install dependencies
pip install -r requirements.txt

# 3. Add your Groq API key
# Edit .streamlit/secrets.toml and replace the placeholder:
# GROQ_API_KEY = "your-groq-api-key-here"
```

### Run locally

```bash
streamlit run app.py
```

The app opens at `http://localhost:8501` in your browser.

---

## Deploy to Streamlit Community Cloud

1. Push the project to a GitHub repository (public or private)
2. Go to [share.streamlit.io](https://share.streamlit.io) and sign in
3. Click **New app** and select your repository, branch, and `app.py` as the entry point
4. Open **Advanced settings** and add your secret:
   ```
   GROQ_API_KEY = "your-groq-api-key-here"
   ```
5. Click **Deploy**

> Do not commit `.streamlit/secrets.toml` to GitHub. Add it to `.gitignore` to keep your API key private.

## AI Models

Uses **Llama 3.3 70B** via the Groq API (`langchain-groq`).

| Function | When it runs | Output |
|---|---|---|
| `interpret_dataset_overview` | After data quality summary loads | 4–5 sentences on dataset type, missing values, and column types |
| `interpret_single_column` | On Column Profile deep-dive | 3–4 sentences on quality, anomalies, and recommended action |
| `interpret_heatmap` | On Heatmap — Multiple Correlations | 3–5 sentences on strongest correlations and unexpected relationships |

All interpretations are cached in `st.session_state` and regenerate only when the user clicks **Refresh** or uploads a new file.
