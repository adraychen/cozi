# 📊 Data Analytics App

A multi-step data analytics tool built with Streamlit. Upload a CSV or Excel file and the app will inspect your data, run a quality audit, visualise each column, and explain the findings in plain English using an AI model.

---

## Features

### Step 1 — Load, Inspect & Interpret

| Section | What it does |
|---|---|
| **File Upload** | Accepts CSV (`.csv`) and Excel (`.xlsx`, `.xls`) files |
| **Dataset Overview** | Displays row and column counts at a glance after upload |
| **Dataset Preview** | Shows the first 100 rows in a scrollable table. Boolean columns display as `True` / `False` text rather than checkboxes |
| **Column Overview** | One row per column showing: Column Name, Data Type, Column Type, Total Values, Missing Values, Missing %. Missing % is colour-coded: red ≥ 20%, yellow 5–19% |
| **Date Override** | Multiselect below the Column Overview table lets you reclassify any column as Date / Time. Columns where fewer than 80% of values parse as dates are rejected with a warning |
| **Data Quality Summary** | Tabbed panel with interactive charts and stats for Numerical, Categorical, and Date / Time columns |
| **AI Interpretation** | Plain-English summary of the dataset generated by Groq (Llama 3.3 70B via LangChain) |

---

## Data Quality Panels

### Numerical Columns
Each column is displayed as a bordered card split into two panels.

**Continuous columns** (15 or more unique values):
- Left: histogram stacked above a boxplot
- Right: Missing Values, Missing %, Unique Values, Minimum, Maximum, Average

**Discrete columns** (fewer than 15 unique values):
- Left: vertical bar chart sorted by frequency, descending. Capped at 10 bars — a note appears when the column has more than 10 unique values
- Right: same stats as continuous

> **Technical note:** The threshold of 15 unique values is used to distinguish discrete from continuous numerical columns. This is defined as `DISCRETE_THRESHOLD = 15` in `utils/charts.py`.

### Categorical Columns
- Left: vertical bar chart of the top 10 most frequent values, sorted descending. A note appears when the column has more than 10 unique values
- Right: Missing Values, Missing %, Unique Values, Case Inconsistency, Special Characters

### Date / Time Columns
- Left: histogram stacked above a boxplot
- Right: Missing Values, Missing %, Earliest Date, Latest Date, Date Range

### Panel Layout
Panels are arranged two per row. If the number of columns is odd, the last panel occupies the left half of the row.

---

## Column Type Detection

The app classifies each column into one of three types:

| Type | Detection logic |
|---|---|
| **Numerical** | Pandas `int` or `float` dtype (excluding `bool`) |
| **Categorical** | Text (`object`) dtype, `bool` dtype, or any column that cannot be reliably parsed as dates |
| **Date / Time** | Pandas `datetime64` dtype, or `object` columns where 80% or more of non-missing values parse as dates |

> **Boolean columns** are classified as Categorical because their values (`True` / `False`) represent discrete categories, not quantities.

---

## Number Formatting

All percentage and numeric stats in the quality panels are formatted to **2 decimal places**:
- Missing %
- Minimum
- Maximum
- Average

## Installation

### Requirements

- Python 3.9 or later
- A [Groq API key](https://console.groq.com) (free tier available)

### Setup

```bash
# 1. Clone or download the project
git clone https://github.com/your-username/data-analytics-app.git
cd data-analytics-app

# 2. Install dependencies
pip install -r requirements.txt

# 3. Add your Groq API key
# Edit .streamlit/secrets.toml and replace the placeholder:
# GROQ_API_KEY = "your-groq-api-key-here"
```

### Run locally

```bash
streamlit run app.py
```

The app opens at `http://localhost:8501` in your browser.

---

## Deploy to Streamlit Community Cloud

1. Push the project to a GitHub repository (public or private)
2. Go to [share.streamlit.io](https://share.streamlit.io) and sign in
3. Click **New app** and select your repository, branch, and `app.py` as the entry point
4. Open **Advanced settings** and add your secret:
   ```
   GROQ_API_KEY = "your-groq-api-key-here"
   ```
5. Click **Deploy**

> **Note:** Do not commit `.streamlit/secrets.toml` to GitHub. Add it to `.gitignore` to keep your API key private.

## AI Model

The app uses **Llama 3.3 70B** served via the Groq API, accessed through LangChain (`ChatGroq`). The model receives a structured summary of the dataset's shape, column types, and quality findings, and returns a plain-English explanation in 4–5 direct sentences.

The interpretation is cached in `st.session_state` and only regenerates when you refresh it manually or upload a new file.
